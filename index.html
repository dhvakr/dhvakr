Systems

Things I built to find out how they work.

Not client work. These exist because reading about a cache is not the same as writing one and then benchmarking it honestly.

DCache

in-memory cache

A thread-safe LRU cache in the spirit of Caffeine: O(1) lookups, per-entry TTL, asynchronous refresh, and a background sweep that expires entries without blocking readers.

JavaConcurrencyLRUTTLExecutorService

50–60K ops/sec, predictable O(1) under concurrent load — measured with JMH.

Rate Limiter

distributed service

A configurable limiter running both token bucket and sliding window over Redis, so API gateway behaviour can be simulated and argued about before it reaches a real gateway.

JavaSpring BootRedisToken bucket

Both algorithms behind one config surface — swap strategy without touching callers.

ikat

The control plane between AI agents and real systems.

Agents can already reach your database, your cloud account and your customers' data. What nobody can answer is what they touched, on whose behalf, and what it cost. Ikat puts scoped identity, policy and a complete record in the path — so security has a way to say yes.
